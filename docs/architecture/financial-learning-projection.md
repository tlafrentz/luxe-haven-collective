# Financial Learning Projection

Presentation calls `GetFinancialLearning` only.

`Immutable expectation snapshots + canonical actuals + execution state → readiness → outcome reviews → forecast accuracy and bias → lessons → knowledge maturity`

The projection consumes bounded Planning, Capital, Cash, Profitability, Portfolio, Decision, Action, and financial evidence ports. Reviews and lessons are append-only and idempotent. Authorization resolves workspace and property scope before sources are read. Cache identity includes scope, permissions, periods, expectation versions, actual sources, review versions, lesson versions, and policy version.
