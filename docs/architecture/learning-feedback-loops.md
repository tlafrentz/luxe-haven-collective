# Learning Feedback Loops

The feedback loop is advisory: a capability supplies an authorized decision context and receives a `RelevantLearningProjection`. Learning never changes assumptions, calculations, scores, recommendations, approvals, pricing, or allocations.

The resolver filters validated same-workspace lessons by capability, applicability, confidence, maturity, evidence coverage, freshness, and policy version. It ranks deterministically and includes every score contribution. Conflicting lessons remain together with an operator-review warning.

Capabilities continue normally when Learning returns no applicable lessons or the advisory read is unavailable.
