# Lesson Domain

Platform Learning owns the relationship from review to assumption result to lesson. It does not own Decisions, Actions, measurements, reports, or feature objects.

Candidate Lessons and Organizational Lessons are distinct aggregates. Published lesson versions are append-only. Applicability is explicit across workspace, portfolio, market, property, property type, strategy, season, guest segment, and operating model; no rule defaults to universal scope.

Relationships preserve support, contradiction, refinement, merges, and supersession. Evidence is referenced, not rewritten. Revisions retain the prior version and its lineage.
