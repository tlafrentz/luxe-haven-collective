# Financial Capital Planning Projection

Presentation calls `GetFinancialCapitalPlanning` only.

`Financial Read Model + Cash/Liquidity + Planning + Portfolio findings + Capital records → Position → Readiness/Constraints/Conflicts → Alternatives → Plan Health → FinancialCapitalPlanning`

Authorization resolves properties before bounded readers execute. Sensitive source, reserve, constraint, alternative, allocation, and availability fields are omitted at the application boundary. Approval records canonical Decision lineage, then creates allocation-scoped Action Center handoffs. Neither execution state nor presentation rewrites financial authority.

Cache identity includes workspace, authorized scope, permissions, period, currency, plan and request revisions, source states, and upstream projection version.
