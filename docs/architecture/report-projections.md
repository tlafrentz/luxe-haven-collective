# Report projections

Every projection identifies its report type, authorized scope, period, summary, ordered sections, qualifications, evidence, confidence, freshness, source versions, projection version, and evaluation time.

Investment projections consume immutable Saved Scenarios. Portfolio and Financial adapters consume their canonical overview projections. Property Reporting remains unavailable until its feature-owned port exists.

Projection adapters remove unauthorized values before snapshot creation. Templates and presentation receive only the filtered projection.
