# Learning Capability Integrations

Investment, Revenue, and Capital integrate through `RelevantLearningPort`; they do not read lesson repositories. Their context includes capability, subject, workspace, and available market, property, property type, strategy, season, guest segment, and operating-model dimensions.

The platform adapter resolves authorization and canonical lesson projections. Presentation renders the returned advisory panel. Feature calculations run before and independently from Learning resolution.

Future capabilities can add context through the same port without importing Learning persistence or changing the resolver contract.
