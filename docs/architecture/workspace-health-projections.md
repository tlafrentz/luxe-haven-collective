# Workspace Health Projections

```text
Organization / Access / Properties / Connections / Quality / Notifications
                              ↓
                    bounded health inputs
                              ↓
                 workspace-readiness-v1
                              ↓
             issues, actions, capabilities, tasks
```

Health evaluation time and provider-data freshness are independent. Material capability events invalidate the composed read; safe recalculation on read remains authoritative.
