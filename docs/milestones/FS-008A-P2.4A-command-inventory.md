# FS-008A-P2.4A — Admin activation command inventory

`executeFurnishingActivationCommand` is the canonical server-side command
boundary. It requires canonical identity, target scope, expected version,
reason, correlation, and idempotency; it performs one transactional state/audit
commit and rejects public enablement.

| Command family | Target | Safe ceiling | Concurrency/audit |
|---|---|---|---|
| Kill switch activate/restore | global/workspace | disabled or restored safe state only | monotonic version, one immutable audit |
| Global activation state | global | disabled/internal/limited/paused | stale conflict, idempotent replay |
| Workspace activation state | workspace | no public enablement | tenant target validation |
| Cohort grant/update/expire/revoke/remove | cohort | no entitlement or commercial activation | tenant target validation and audit |
| Capability state | capability | commercial/customer effects remain disabled | safe-ceiling transition validation |

Owners, operators, wrong-tenant users, and anonymous callers fail authorization.
Admin UI is intentionally out of scope for P2.4A.
