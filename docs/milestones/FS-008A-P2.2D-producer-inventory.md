# FS-008A-P2.2D — Furnishing producer inventory

The canonical producer boundary is `createFurnishingNotificationIntent` in
`src/platform/notifications/furnishing-notification-intent.ts`. It fixes the
typed `productFamily: "furnishing"` value and namespaces event kinds; callers
cannot omit, clear, or replace it. Persistence, worker hydration, retry/replay,
bulk, manual resend, and channel adapters are covered by the P2.2B/C envelope
and adapter tests.

| Furnishing workflow | Producer status | Canonical guard/test |
|---|---|---|
| Project creation/status | No active enqueue call site; factory kind covered | typed factory + outbox round-trip |
| Customer onboarding | No active enqueue call site; factory kind covered | typed factory + suppression |
| Design review/approval | No active enqueue call site; factory kinds covered | typed factory + suppression |
| Budget approval/exception | No active enqueue call site; factory kinds covered | typed factory + suppression |
| Procurement readiness/order | No active enqueue call site; factory kind covered | typed factory + suppression |
| Product replacement/availability | No active enqueue call site; factory kind covered | typed factory + suppression |
| Installation scheduling/status | No active enqueue call site; factory kinds covered | typed factory + suppression |
| Launch readiness | No active enqueue call site; factory kind covered | typed factory + suppression |
| Admin manual notification | No active enqueue call site; factory kind covered | typed factory + suppression |
| Recurring/scheduled workflows | No active enqueue call site; `scheduled-reminder` covered | envelope mode + suppression |
| Failure/recovery/reminder/escalation | No active enqueue call site; factory kinds covered | retry/replay + suppression |

No Furnishing producer currently emits a notification intent in the application
tree, so no existing producer was silently changed to add customer contact
behavior while FS-008A is disabled. Any future Furnishing producer must use the
factory; direct or ambiguous persisted values fail closed during hydration.
Unrelated notification producers retain their existing optional product-family
behavior.
