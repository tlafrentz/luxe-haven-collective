# Workspace Product Blueprint

| Field | Definition |
|---|---|
| Mission | Configure the hospitality business so every Luxe Haven product operates correctly |
| Primary users | Owner, portfolio operator, small hospitality team |
| Business question | How is my hospitality business configured? |
| Primary action | Complete the highest-priority setup requirement |
| Health model | Configuration: organization, team, properties, connections, notifications, preferences |
| Dominant pattern | Settings sections |
| Density | Comfortable |
| Local navigation | Section navigation as configuration becomes editable |
| Supporting information | Connection guidance and onboarding dependencies |
| History model | Low-volume activity timeline |
| Success metrics | Time to core setup, configuration completion, successful source connection |
| Out of scope | Internal support, provider monitoring, infrastructure, audit |

First use explains business setup and begins with Organization. Attention identifies a missing or stale connection and its effect. Degraded state preserves configuration while identifying unavailable connected data. Permission state distinguishes workspace management from view access. Archive does not apply to Workspace itself; archived members or properties remain owned by their source workflows.

Desktop uses a medium-width comfortable configuration surface. Mobile prioritizes completion state, the next setup action, configuration sections, connection guidance, and recent changes.
