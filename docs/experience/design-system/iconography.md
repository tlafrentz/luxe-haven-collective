# Iconography

Luxe Haven uses one consistent line-icon family with stable optical size and stroke character.

Rules:

- One icon per routable product.
- Icons support labels and never replace unfamiliar text.
- Icon-only buttons require accessible names.
- Product icon roles remain stable across navigation and headers.
- Status icons use semantic state treatment and accompanying text.
- Decorative icons are rare.
- Routine empty states do not require custom illustration.

Canonical semantic roles are exported from `@/design-system/icons`. Product roles describe meaning rather than binding consumers to a particular library glyph, allowing controlled icon-family evolution.
