# Typography

## Semantic roles

| Role | Use |
|---|---|
| Display | Rare high-level product or publishing moment |
| Page title | One route-level H1 |
| Section title | Major H2 region |
| Panel title | Card/panel H3 |
| Body | Default explanation and content |
| Body strong | Meaningful emphasis |
| Label | Form/control label |
| Caption | Supporting explanation |
| Metadata | Time, source, actor, version |
| Code | Identifiers and technical values |

## Rules

- One page title per route.
- Semantic heading order is independent of visual styling.
- Product titles remain consistent across workspaces.
- Body copy prioritizes readability over brand expression.
- Reports may use controlled editorial typography without changing application controls.
- Numeric metrics use consistent alignment and tabular numerals where available.
- Font size is never selected solely to make a layout fit.
- Metadata remains readable and meets contrast requirements.

The application uses Geist for interface text and Playfair Display only for deliberate editorial or guest-facing brand expression.
