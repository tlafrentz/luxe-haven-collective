# Data Visualization

Charts exist to clarify decisions, not decorate dashboards.

## Required anatomy

Every visualization identifies its title, scope, unit, time range, source or freshness when relevant, and an accessible alternative. Important changes receive a nearby explanation connecting state, evidence, interpretation, and action.

## Rules

- Use the fewest series necessary and preserve comparable scales.
- Do not use color as the only distinction; combine it with labels, shapes, line styles, or patterns.
- Distinguish measured actuals from forecasts and missing data from zero.
- Make tooltips keyboard accessible where practical; never place essential facts only in a tooltip.
- Avoid 3D charts. Use gauges only for meaningful, defensible bounded scales.
- Use tabular numerals and visible units.
- Keep source evidence traceable and do not calculate a competing business evaluation in the view layer.

## Approved families

Line, bar, stacked bar, sparing area, scatter, distribution, waterfall, comparison table, and score breakdown.

| Information | Treatment |
| --- | --- |
| Measured actual | Solid mark or line |
| Forecast | Dashed or patterned treatment plus label |
| Missing | Explicit gap or “No data” marker |
| Zero | Plotted zero with its normal scale |
| Comparison | Consistent scale and directly named series |

Light and dark modes must preserve hierarchy, contrast, series distinction, focus, and readable annotations.
