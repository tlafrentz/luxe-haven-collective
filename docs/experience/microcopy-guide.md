# Microcopy Guide

## Voice

Use calm, direct operator language. Prefer verbs and concrete nouns. Remove promotional framing, repeated platform names, and implementation detail that does not help a decision.

## Page purpose

One sentence should explain what the operator can understand or accomplish. Example:

> Arrivals, active stays, departures, and open issues for today.

## Status vocabulary

- Preview
- Coming Soon
- Unavailable
- Needs Connection
- Needs Data
- Loading
- Error

Avoid ambiguous `Pending`, `Soon`, or `Disabled` without a cause.

## Empty states

State why content is empty and name the next meaningful action:

> Learning is empty because no portfolio is selected. Choose a portfolio to review measured outcomes.

## Controls

Button labels use a verb and object: `View bookings`, `Choose portfolio`, `Apply filters`, `Hide calculation`. Avoid `Continue` when a more specific outcome is known.

## Specialized concepts

Keep the visible label concise and provide shared contextual help:

- Confidence: strength and completeness of evidence, not performance.
- Freshness: time since the underlying evidence was observed.
- Availability: whether the capability has enough data and connection support.
- Evidence: the facts supporting a displayed conclusion.
