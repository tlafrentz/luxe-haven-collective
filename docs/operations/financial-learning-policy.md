# Financial Learning Policy

A review is ready only after execution completes, the review date elapses, evidence coverage is sufficient, and actual-result confidence meets policy. Otherwise it remains Not Ready, Insufficient Evidence, or Degraded.

Forecast evaluation records absolute error, percentage error, signed bias, direction, accuracy classification, and trend. Zero expected values do not produce percentage error. Assumptions are Confirmed, Partially Confirmed, Invalidated, or Unable to Evaluate.

Confidence adjustments apply only to future confidence. Knowledge maturity progresses from Emerging to Supported, Established, and Well Validated using accumulated evidence-backed lessons and review lineage. Historical records remain unchanged.
