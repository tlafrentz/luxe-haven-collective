# Outcome Review Runbook

For a waiting review, inspect execution evidence, window timing, settlement delay, and missing requirements. For a failed job, confirm the source adapter and scope, then retry only retryable failures after its lease expires.

For missing automatic data, record an authorized manual measurement only when policy permits. Select the authoritative measurement explicitly. Complete as Unable to Evaluate when evidence remains insufficient.

Never edit a completed review, baseline, evaluation, or selected measurement. Create a correction revision, record the reason and actor, re-evaluate, then supersede the former review.
