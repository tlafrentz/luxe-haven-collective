# Learning Governance

Learning evolves only through authorized, evidence-backed commands. Validation, revisions, supersession, retirement, merges, contradiction resolution, calibration, and retries append governance history.

Operational administrators can inspect metadata, health, queues, distributions, alerts, and job failures. Administrative metadata access does not automatically expose restricted customer measurements or evidence contents.

Learning never changes source Decisions, Recommendations, financial models, Investment calculations, or pricing logic.
