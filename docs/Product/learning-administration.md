# Learning Administration

Learning Administration provides health, calibration, lesson governance, review queues, contradiction management, safe retries, coverage, distributions, growth, latency, and alerts under `/admin/learning`.

Operators can understand whether Learning is healthy without inspecting database tables. The interface intentionally separates confidence from maturity and operational metadata from restricted customer evidence.

Empty, degraded, retry, contradiction, calibration-required, and permission-limited states remain explicit.
