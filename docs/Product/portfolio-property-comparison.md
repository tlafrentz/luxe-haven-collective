# Portfolio Property Comparison

`/dashboard/portfolio/properties` answers which authorized properties contribute
to results, which are changing, how efficiently they operate, how much operating
attention they consume, and whether the evidence supports comparison.

The product deliberately has no universal “best” or “worst” property. Rankings
are decision-specific and disclose their metric, period, normalization,
eligibility, missing properties, and tie tolerance. Roles are descriptive,
explainable, versioned classifications and never create a recommendation,
decision, or action.

The desktop table uses a focused metric set. Mobile uses property cards rather
than compressing the table into horizontal scrolling. Selecting a property opens
comparison-aware detail without duplicating the operational Property product.
