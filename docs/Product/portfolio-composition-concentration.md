# Portfolio Composition & Concentration

`/dashboard/portfolio/composition` describes what the authorized portfolio
contains and measures structural dependencies independently.

Composition reports markets, geography, property types, bedroom mix, operating
models, acquisition strategies, booking sources, revenue, bookings, and
seasonality. Concentration always names its basis; it never displays an
unqualified “high concentration” label.

Diversification is expressed as breadth across properties, markets, types,
models, strategies, and booking sources. There is no diversification score and
no recommendation about whether the observed structure is desirable.
