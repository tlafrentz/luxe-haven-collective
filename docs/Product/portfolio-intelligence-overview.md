# Portfolio Intelligence Overview

`/dashboard/portfolio` answers how the authorized properties are performing
together, what changed, which properties drive the result, and how reliable the
analysis is. It is distinct from Executive Intelligence, which prioritizes
leadership attention across the whole business.

The reading order is condition, primary metrics, material changes, contribution,
attention, composition, execution, then evidence. Empty, one-property,
permission-limited, insufficient-evidence, stale/degraded, no-comparison,
no-change, no-execution, loading, and error states retain available facts.

The Overview never creates recommendations, decisions, actions, scores, risk
classifications, or causal claims. Property contribution is explicitly
mathematical.
