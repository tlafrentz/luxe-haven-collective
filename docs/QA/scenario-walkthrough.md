# Scenario Walkthrough

1. Open an Opportunity and select **Compare scenarios**.
2. Verify the original analysis appears as Base Scenario and the current analysis is Preferred.
3. Create a scenario through reanalysis, modify assumptions, calculate, and save it to the same Opportunity.
4. Confirm both historical snapshots remain unchanged and independently reportable.
5. Compare two to four scenarios and verify revenue, expense, NOI, cash flow, returns, occupancy, score, recommendation, confidence, and changed assumptions.
6. Confirm difference direction follows metric policy and unavailable values remain unavailable.
7. Open a scenario detail and verify calculation, engine, evidence, and recommendation versions.
8. Validate empty, partial evidence, inaccessible Opportunity, keyboard, screen-reader, tablet, and mobile states.
9. Run relevant tests, full tests, typecheck, lint, build, route validation, and `git diff --check`.
