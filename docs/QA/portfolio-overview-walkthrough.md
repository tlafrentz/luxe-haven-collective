# Portfolio Overview QA Walkthrough

1. Open `/dashboard/portfolio` as an Owner and verify “Full Workspace Portfolio.”
2. Repeat as an assigned Operator or Viewer and verify no inaccessible names,
   totals, actions, or workspace counts appear.
3. Exercise 30-day, 90-day, YTD, and trailing-12-month presets with previous
   period, previous year, and no comparison.
4. Verify revenue, ADR, occupancy, RevPAR, and bookings reconcile to included
   property facts; confirm NOI is unavailable when expenses are absent.
5. Confirm scope changes produce a disclosure.
6. Confirm stable, strong, attention, at-risk, insufficient-evidence,
   one-property, no-property, stale, loading, and error states.
7. Navigate by keyboard through every control and link. Verify visible focus,
   semantic headings, textual status, and no horizontal metric table on mobile.
8. At 375px, 768px, and 1440px, verify reading order remains condition, metrics,
   changes, contribution/attention, composition/execution, evidence.
9. Confirm logs contain only bounded diagnostic fields and no financial values,
   guest data, credentials, or evidence payloads.
